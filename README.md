Project Name : Todo App

Project is about creating Todo list , toggle button for completing todos , delete button for deleting todos . 
Search functionality to search todos and Filter for complete and incomplete todos .

Technology: Javascript, React,Redux, Html5,Css3 ,Tailwind Css
